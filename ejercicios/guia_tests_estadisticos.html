1 Presentación

Esta guía practica todo el ciclo de un test de hipótesis sobre datos reales de la Encuesta CEP N°95: desde plantear \(H_0\) y \(H_a\) hasta redactar una conclusión sustantiva. A diferencia de la guía anterior —centrada en describir y estimar— aquí el foco está en decidir: contrastar el valor observado en la muestra contra un valor de referencia y evaluar si la diferencia es estadísticamente significativa en la población.

El encargo: Un centro de estudios les pide evaluar formalmente varias afirmaciones sobre las actitudes políticas de la población chilena. Algunas comparan un promedio con un valor teórico (¿la población es de centro?), otras comparan dos grupos (¿piensan distinto hombres y mujeres?), y otras comparan dos mediciones sobre las mismas personas. Además, deberán mostrar que entienden qué puede salir mal al decidir: los errores tipo I y tipo II.

3 La lógica del test (repaso) y los tipos de error

Antes de calcular, fijemos el vocabulario. Todo test tiene cinco componentes: supuestos, hipótesis (\(H_0\) y \(H_a\)), estadístico de prueba, valor-p y conclusión. La regla de decisión es siempre la misma:

\[\text{valor-}p < \alpha \;\Rightarrow\; \text{se rechaza } H_0.\]

Al decidir con datos podemos equivocarnos de dos formas. Conviene tenerlas claras antes de resolver los ejercicios, porque cada conclusión que redacten arrastra este riesgo.

\(H_0\) es verdadera \(H_0\) es falsa
Rechazamos \(H_0\) Error tipo I (prob. \(\alpha\)) Decisión correcta (potencia = \(1-\beta\))
No rechazamos \(H_0\) Decisión correcta Error tipo II (prob. \(\beta\))
  • Error tipo I (\(\alpha\)): rechazar \(H_0\) cuando en realidad es verdadera (“falso positivo”). Lo fijamos nosotros: usar \(\alpha = 0.05\) es aceptar de antemano equivocarnos así un 5% de las veces.
  • Error tipo II (\(\beta\)): no rechazar \(H_0\) cuando en realidad es falsa (“falso negativo”).
  • Potencia (\(1-\beta\)): probabilidad de detectar un efecto que sí existe. Crece con el tamaño muestral, con el tamaño del efecto y con un \(\alpha\) más laxo.
Importante

Redacción. Cuando el valor-p es mayor a \(\alpha\) no decimos que “aceptamos” o “probamos” \(H_0\): decimos que no hay evidencia suficiente para rechazarla. La diferencia no es cosmética —- afirmar \(H_0\) es justamente arriesgar un error tipo II sin cuantificarlo.

4 Test para una media

4.1 Dos colas — ¿la población es de centro? (ejemplo resuelto)

Si la población fuera ideológicamente “de centro”, su promedio en la escala 1–10 sería el punto medio, 5.5. Contrastamos:

\[H_0: \mu = 5.5 \qquad H_a: \mu \neq 5.5\]

El estadístico de prueba mide a cuántos errores estándar está la media muestral del valor de \(H_0\):

\[t = \frac{\bar{x} - \mu_0}{se}, \qquad se = \frac{s}{\sqrt{n}}\]

# Insumos
media_ideo <- mean(cep$ideologia, na.rm = TRUE)
sd_ideo    <- sd(cep$ideologia,   na.rm = TRUE)
n_ideo     <- sum(!is.na(cep$ideologia))

# Error estándar y estadístico t (a mano)
se_ideo <- sd_ideo / sqrt(n_ideo)
t_ideo  <- (media_ideo - 5.5) / se_ideo

5 Correspondencia entre el test de dos colas y el intervalo de confianza

Un test de dos colas al 95% y un intervalo de confianza al 95% para el mismo estadístico siempre son coherentes: si el test rechaza \(H_0: \mu = \mu_0\), entonces \(\mu_0\) queda fuera del intervalo; si no lo rechaza, \(\mu_0\) queda dentro.

# IC al 95% para la media de ideologia
t.test(cep$ideologia, conf.level = 0.95)$conf.int
[1] 5.419936 5.746030
attr(,"conf.level")
[1] 0.95

6 Test para una proporción

Con variables categóricas hacemos inferencia sobre una proporción: comparamos la proporción muestral \(\hat{p}\) con un valor de referencia \(\pi_0\).

\[t = \frac{\hat{p} - \pi_0}{se}, \qquad se = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\]

7 Muestras independientes: comparar dos grupos

Hasta aquí comparamos un estadístico contra un valor fijo. Ahora comparamos dos grupos distintos de personas (hombres vs. mujeres, urbano vs. rural). Como son grupos separados, las muestras son independientes. El error estándar combina la variabilidad de ambos grupos:

\[t = \frac{\bar{x}_1 - \bar{x}_2}{se}, \qquad se = \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}\]

7.1 ¿Difiere la posición ideológica entre hombres y mujeres? (ejemplo resuelto)

\[H_0: \mu_{\text{hombres}} = \mu_{\text{mujeres}} \qquad H_a: \mu_{\text{hombres}} \neq \mu_{\text{mujeres}}\]

# Medias, desviaciones y n por grupo
m_h <- mean(cep$ideologia[cep$mujer == 0], na.rm = TRUE)
m_m <- mean(cep$ideologia[cep$mujer == 1], na.rm = TRUE)
s_h <- sd(cep$ideologia[cep$mujer == 0],   na.rm = TRUE)
s_m <- sd(cep$ideologia[cep$mujer == 1],   na.rm = TRUE)
n_h <- sum(!is.na(cep$ideologia[cep$mujer == 0]))
n_m <- sum(!is.na(cep$ideologia[cep$mujer == 1]))

# Error estándar y estadístico t (a mano, versión de Welch)
se_dif <- sqrt(s_h^2 / n_h + s_m^2 / n_m)
t_dif  <- (m_h - m_m) / se_dif

8 Muestras dependientes (pareadas): comparar dos mediciones

Las muestras son dependientes (o pareadas) cuando las dos mediciones provienen de las mismas personas: por ejemplo, evaluar dos instituciones en la misma escala, o comparar una evaluación “antes” y “después”. La clave es que cada persona aporta un par de valores, por lo que analizamos la diferencia individual \(d_i = x_i - y_i\):

\[t = \frac{\bar{d}}{se}, \qquad se = \frac{s_d}{\sqrt{n}}\]

Nota

¿Qué cuenta como pareado en el CEP? Cualquier par de ítems respondidos por la misma persona en una escala comparable. Ejemplos típicos: nota de evaluación a dos autoridades o instituciones; percepción de la situación económica actual vs. futura; confianza en el gobierno vs. confianza en el Congreso. Elijan un par de este tipo y reemplacen item_1 / item_2 por los nombres reales del libro de códigos del CEP N°95.

9 Tipos de error, en la práctica

La teoría de la sección 2 se puede ver con simulaciones. Aquí no analizamos el CEP, sino que generamos datos donde sabemos cuál es la verdad, y observamos con qué frecuencia el test se equivoca.

9.1 Error tipo I: cuando \(H_0\) es verdadera

Generamos 2000 muestras de una población donde \(H_0: \mu = 5.5\) es verdadera y contamos qué proporción de tests la rechaza al 5%. Debería acercarse a… 0.05.

set.seed(2024)
p_valores <- replicate(2000, {
  muestra <- rnorm(n = 40, mean = 5.5, sd = 2.3)  # H0 es verdadera
  t.test(muestra, mu = 5.5)$p.value
})

mean(p_valores < 0.05)   # tasa empírica de error tipo I
[1] 0.0415

Pregunta 7.1: El resultado ronda 0.05 aunque \(H_0\) era verdadera en todas las muestras. Explique en qué sentido ese 5% de rechazos son, por definición, errores tipo I. ¿Qué pasaría con esta tasa si usáramos \(\alpha = 0.01\)?

9.2 Error tipo II y potencia: cuando \(H_0\) es falsa

Ahora la verdad es \(\mu = 5.9\) (la población no es de centro), pero seguimos testeando contra 5.5. Cada vez que el test no rechaza, comete un error tipo II.

set.seed(2024)
rechazos <- replicate(2000, {
  muestra <- rnorm(n = 40, mean = 5.9, sd = 2.3)  # H0 es FALSA
  t.test(muestra, mu = 5.5)$p.value < 0.05
})

mean(rechazos)        # potencia estimada (1 - beta)
[1] 0.1755
1 - mean(rechazos)    # tasa de error tipo II estimada (beta)
[1] 0.8245
# Cálculo analítico de la potencia con la misma configuración
power.t.test(n = 40, delta = 5.9 - 5.5, sd = 2.3,
             sig.level = 0.05, type = "one.sample")

10 Conclusiones del informe

10.1 Ejercicio final (integrador)

Redacte un párrafo de conclusiones (8–12 líneas) que integre los principales hallazgos, como cerraría un informe real. Debe incluir, con su respaldo estadístico:

  1. El resultado del test sobre la posición ideológica de la población (¿es de centro?), con su conclusión sustantiva.
  2. El resultado del test sobre la aprobación del gobierno.
  3. Al menos una comparación entre grupos (muestras independientes o pareadas), nombrando la dirección y el tamaño de la diferencia.
  4. Una frase sobre el riesgo de error asumido: qué \(\alpha\) usó y qué significa en términos de error tipo I.

Criterio de calidad: un buen párrafo no dice “el valor-p fue 0.03”, sino “la evidencia permite descartar que la población se ubique en el centro exacto de la escala (p < 0.05); el promedio poblacional se estima entre X e Y, y la diferencia entre hombres y mujeres, aunque significativa, es de apenas Z puntos”.
